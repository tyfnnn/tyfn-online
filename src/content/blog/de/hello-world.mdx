## Warum MDX

Mit MDX schreibe ich ganz normales Markdown für den Fließtext und kann
bei Bedarf Astro-Komponenten einstreuen — ein Code-Sample, ein Embed
oder ein kleines Diagramm — ohne die Datei zu wechseln.

```ts
import { getCollection } from 'astro:content';

const posts = await getCollection('blog', (e) => e.data.lang === 'de');
```
